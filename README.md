# CodeFactory To-Do API

## Descrição do projeto
API REST de lista de tarefas desenvolvida para demonstrar a adoção da Cultura DevOps pela CodeFactory Solutions, no contexto da atividade prática de DevOps e Integração Contínua (UNINTER).

## Tecnologias utilizadas
- Python 3.12 + Flask
- SQLite
- Pytest

## Como executar com Docker
```bash
docker compose up
```
A API ficará disponível em http://localhost:5000.
